02 / WebView

WebView device logging for hybrid apps.

Capture JavaScript console calls and uncaught exceptions from inspectable Android and iOS WebViews. View WebView console output alongside native logs from the same device, merged by timestamp.

A hybrid app brings a web app running in a WebView together with native code. Web app logging alone shows only part of the picture. Über Device Log provides combined logging: see JavaScript console output alongside native logs from the same device, merged by timestamp with each source identified. If your app uses multiple inspectable WebViews, you can include their consoles too.

Search each source independently, filter Android and WebView severity, and export entries with their source identity intact. Native iOS syslog has no severity filter.

Android apps must enable WebView debugging. On iOS, enable Safari’s Web Inspector and expose the app’s WKWebView for inspection. No additional proxy, browser extension or Appium server required.

Android Logcat and iOS syslog on macOS, Windows and Linux

Android Logcat uses ADB from Android SDK Platform Tools on macOS, Windows and Linux. For iPhone and iPad syslog, macOS uses Apple’s device service; Linux needs usbmuxd, and Windows needs compatible Apple mobile-device support. macOS is the primary validation environment; Windows and Linux still need validation.

05 / Get started →

One command. Then connect.

Requires Node.js 22.12.0 or later and a browser. Node.js must be on PATH, even with bunx. Run with npx or bunx, or install globally and launch with udl.

iOS capture uses the legacy syslog relay (com.apple.syslog_relay), not the full Apple unified logging system shown in Console or Xcode. Unlock and trust the device; available logs depend on the device and iOS version.
