Fictional loading progress emitter

Developer fixture: buttons only emit JSON console messages. They make no network requests and do not download resources. Every click uses a fresh loadId, so multiple examples can run concurrently.

Open this page in an inspectable WebView. Start Über Device Log with --project=./test_flow_project, include the WebView, and open Flows. Select Detailed or Condensed to inspect updates to the same flow label and percent result. Timeline retains the accepted progress observations.

Backward progress is shown as received, without inventing a monotonic percentage. Progress does not extend the 30-second deadline. A timeout means completion was not observed, rather than proving a loader failure.
